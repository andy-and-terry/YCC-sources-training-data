# dumps/

Drop real code dumps here. Anything placed in this directory is treated as
external/real-world source material (as opposed to `training-data/`, which
currently holds small hand-authored illustrative samples, and `scripts/`,
which holds the puller script for pulling real corpora on demand).

When files land here, tell Claude and it will sort/organize/dedupe them into
`training-data/<language>/` as appropriate.

This directory is otherwise kept empty (`.gitkeep`) so it survives being
tracked by git before anything is dropped in.
